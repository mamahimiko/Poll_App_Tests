## Feedback on the Tests

### Additional Tests

The existing tests covered most of the functionality, so I did not need to add any additional tests.
Initially, the dropdown was implemented using HTML `<option>` elements, and the test used the following code:


fireEvent.change(changeDropdown, { target: { value: "option-6" } });


However, when I changed the screen size to a mobile layout, the design did not work as expected. Therefore, I implemented the dropdown without using `<option>` elements.
As a result, I changed the test to:


const changeDropdown = screen.getByTestId("change-vote-option");
fireEvent.click(changeDropdown);


This allowed the test to work with the updated dropdown implementation while preserving the existing test coverage.

### How Could the Tests Have Been Improved?

The tests covered the functionality quite thoroughly. Both the unit tests and integration tests covered important features, including image rendering, tab navigation, and status updates. 
The comments in the tests were also clear and helpful.
I did not identify any significant gaps in the test coverage. Overall, the existing tests provided enough information to reproduce the application's main functionality.
